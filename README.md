# 🌾 ANN Rice Blending Verification

## 📌 Overview

A MATLAB-based computer vision system for automatic rice grain classification and blending ratio verification using image processing and Artificial Neural Networks (ANN).

## 🚀 Key Features

- Marker-Controlled Watershed segmentation
- Morphological feature extraction
- ANN (MLP) classification
- Blending ratio estimation
- Visual result annotation

## 🛠️ Tech Stack

- MATLAB
- Image Processing Toolbox
- Deep Learning Toolbox
- Artificial Neural Networks (MLP)
